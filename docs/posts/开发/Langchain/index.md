# LangChain 教程

从入门到进阶的 LangChain 完整教程，涵盖核心概念、LCEL 表达式语言、RAG 检索增强生成、工具调用与 Agent、LangGraph 等内容。

## 教程目录

1. **LangChain 概述与环境搭建** — 核心架构、安装配置、快速上手
2. **LangChain 模型与提示词** — Chat Models、Prompt Templates、Output Parsers
3. **LangChain LCEL 表达式语言** — Runnable 协议、管道运算符、并行与分支
4. **LangChain RAG 检索增强生成** — 文档加载、文本分割、向量存储、检索链
5. **LangChain 工具与 Agent** — Tool 定义、Tool Calling、ReAct Agent
6. **LangGraph 构建复杂 Agent** — StateGraph、多步推理、人机协作

## 适用人群

- 有 Python 基础的开发者
- 想要基于 LLM 构建应用的工程师
- 对 RAG、Agent 等 AI 应用架构感兴趣的同学
