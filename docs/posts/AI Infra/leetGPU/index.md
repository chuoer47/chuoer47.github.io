# LeetGPU

[LeetGPU](https://leetgpu.com/) 刷题笔记：一个在线 GPU 编程刷题平台，无需本地 CUDA 环境，在浏览器里写 CUDA kernel 并直接在云端 GPU 上运行、判题。

> 本人是刷题过程中记录的解法与要点，非官方答案，可能存在理解错误。
