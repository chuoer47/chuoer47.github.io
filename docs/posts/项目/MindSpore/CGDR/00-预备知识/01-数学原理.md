# 01 · 数学原理：ChunkGatedDeltaRule 在算什么

在看任何 AscendC 代码之前，必须先弄清楚算子的数学语义。否则 kernel 里每个循环为什么是三角形的、为什么有一个"递归修正"步骤、为什么 state 要转置，全都看不懂。

## 1. 算子的来源

ChunkGatedDeltaRule 是 **Gated DeltaNet**（门控 Delta 网络）类线性注意力的 **chunkwise（分块）训练算子**。它对应的推理/训练公式来自 DeltaNet 一脉的线性注意力模型（Gated DeltaNet，也是 Qwen3-Next 等模型使用的线性注意力层）。

与标准 softmax attention 不同，DeltaNet 维护一个**循环状态矩阵** S，逐 token 递推更新：

$$S_t = \alpha_t S_{t-1} + \beta_t k_t (v_t - k_t^\top S_{t-1})^\top$$

拆开看这个递推的每一项：

| 记号 | 含义 | 对应算子输入 |
|---|---|---|
| $S \in \mathbb{R}^{d_k \times d_v}$ | 循环状态（"记忆"矩阵） | `initialState` (FP16)，最终写回 `finalState` |
| $k_t \in \mathbb{R}^{d_k}$ | key 向量 | `key`，布局 `[T, Nk, dk]` |
| $v_t \in \mathbb{R}^{d_v}$ | value 向量 | `value`，布局 `[T, Nv, dv]` |
| $\beta_t \in (0,1)$ | 写入强度（决定这步"写多少"进记忆） | `beta`，布局 `[T, Nv]` |
| $\alpha_t = e^{g_t}$ | 遗忘门（g 是 log 域衰减，负数，所以 $e^{g} \le 1$） | `g`（可选输入，FP32），布局 `[T, Nv]` |
| $q_t$ | query 向量（读记忆） | `query`，布局 `[T, Nk, dk]`，带缩放 `scale` |
| `actualSeqLengths` | 每个 batch 的真实序列长度 | 变长序列支持 |

每一步 t：
1. 用 query 读旧记忆：$q_t^\top S_{t-1}$（这就是"注意力"输出的一部分）；
2. 计算"应该写入的增量"：$v_t - k_t^\top S_{t-1}$（当前记忆能解释多少 $v_t$，补差值——这就是 **Delta Rule** 名字的由来）；
3. 先遗忘（乘 $e^{g_t}$），再按强度 $\beta_t$ 把增量写进记忆。

输出：
- `out[t]` = 该步的注意力输出（由 $q_t$ 读历史记忆 + 块内互注意力组成，见下文）；
- `finalState` = 序列结束时的状态 $S_T$。

注意 $\beta_t$ 和 $g_t$ 是 **per-value-head** 的（布局 `[T, Nv]`），而 $k, q$ 是 per-k-head（`[T, Nk, dk]`）。通常 $Nv$ 是 $Nk$ 的整数倍，每 $Nv/Nk$ 个 V-head 共享一个 K/Q-head —— kernel 里 `nvPerNk = NV_/NK_`、`qkHead = head_i / nvPerNk` 就是干这个的（见 04 篇）。

## 2. 为什么分块（chunkwise）？

朴素递推是 $O(T)$ 串行的，GPU/NPU 上没法并行。chunkwise 算法把长度 T 的序列切成 $\lceil T/64 \rceil$ 个块（`chunkSize=64`，与 910B 版本对齐，是硬编码常量），然后：

- **块内**：64 个时间步之间的"互注意力"用一个小矩阵乘一次性并行算出（递推在块内被展开成矩阵形式）；
- **块间**：块与块之间只传一个状态矩阵 S，仍然串行，但串行次数从 T 次降到 T/64 次。

这是 flash-linear-attention 系列的标准做法，块内矩阵大小 64×64，正好可以放进片上存储。

## 3. 块内数学：把递推展开成矩阵

对一个块内的 64 步递推做代数展开（这是整个 kernel 的数学骨架）。记块内第 $i$ 步（$i = 0..L-1$，$L \le 64$ 是 `chunkLen`），定义：

- $\gamma_i = e^{g_i}$（遗忘因子），$g_i$ 的块内前缀和 $G_i = \sum_{j \le i} g_j$（代码里的 `gCumsumFp32`），跨步衰减 $e^{g_i - g_j} = e^{G_i - G_j}$（这就是 `decayMaskFp32`）；
- $k^{(\beta)}_i = \beta_i k_i$（`kCumdecayFp32` 的初值，Phase 2 `ComputeKBeta`）；
- $v^{(\beta)}_i = \beta_i v_i$（`chunkVFp32` 的初值，Step 1 `LoadVBeta`）。

### 3.1 块内互注意力矩阵 A（含 delta rule 的递归修正）

块内 $j < i$ 时，第 $i$ 步看到的"第 j 步写入的残余"不是简单的前缀和，因为每步写入的量本身被后面步骤的读取-擦除修正过。展开后 $A_{ij}$ 满足一个下三角递推：

$$A_{ij} = -\, e^{G_i - G_j} \cdot \beta_i k_i^\top k_j \;+\; \sum_{j < m < i} A_{im} \cdot \big(e^{G_m - G_j}\beta_j k_m^\top k_j\big)$$

即：**直接衰减项 + 间接路径修正**。代码里分两步实现：

1. 先算"直接项"矩阵（Phase 4 `ComputeAttnMatrix` 前半段）：
   `A[i][j] = -(k_beta[i] · k[j]) * decayMask[i][j]`，其中 `k_beta[i]·k[j]` 用向量点积 `DotFp32` 算出，乘上 `decayMask`（即 $e^{G_i-G_j}$）取负。
2. 再做**递归修正**（`ComputeRecursiveAttn`）：按行迭代，`row_i += A[i][k] * row_k`（k 从小到大），把间接路径补上。这是纯下三角递推，串行但每步是一条向量指令 Axpy。

最后对角线置 1（`A[i][i] = 1`）：写入自己这一步的增量是完整保留的。

### 3.2 块内输出与状态更新（kernel 的 7 个公式）

有了 A 和 $\gamma$，块的输入输出关系可以全部写成矩阵形式：

**(1) k_cumdecay**（Phase 5 `ComputeKCumdecay`，结果覆盖进 `chunkKFp32`）：

$$K_{cd} = A \cdot \mathrm{diag}(\gamma)\, K_\beta$$

含义：每步的 key 按块内衰减路径"衰减到块尾"之后的等效 key。它用于把**旧状态的贡献从写入里扣除**。

**(2) 块内新值**（Step 2 `ComputeValueNew` → `chunkAttnOutFp32`）：

$$\mathrm{value\_new} = A \cdot V_\beta$$

即块内经典的因果注意力输出（对角线为 1，所以包含"自己"）。

**(3) 减去旧状态贡献**（Step 4 `ComputeVNew` → 覆盖回 `chunkVFp32`）：

$$v_{new} = \mathrm{value\_new} - K_{cd} \cdot S_{in}$$

含义：递推里每步写入的是 $v - k^\top S$，把"旧状态已经解释的部分"从 $v$ 里减掉，剩下的才是真正要写进记忆的新增信息。

**(4) 跨块注意力**（Step 5 `ComputeAttnInter` → 写入 `chunkAttnOutFp32`）：

$$\mathrm{attn\_inter} = (\mathrm{diag}(e^{G_i})\, q_i \cdot scale) \cdot S_{in}$$

含义：第 $i$ 步用 query 读**块开始时刻**的记忆，读到的量已经按 $e^{G_i}$ 衰减。

**(5) 最终输出**（Step 6 `AccumOutput`，累加进 `chunkAttnOutFp32`）：

$$\mathrm{out}_i = \mathrm{attn\_inter}_i + \sum_{j \le i} e^{G_i - G_j} (q_i^\top q?? k_j) \cdot scale \cdot v_{new,j}$$

准确写法：`out = attn_inter + tril(QK^T ⊙ decay) · v_new`。其中 `tril(QK^T ⊙ decay)` 就是 Phase 4 后半段重写进 `decayMaskFp32` 的矩阵（原来存 $e^{G_i-G_j}$ 的缓冲被原地覆盖成 $(q_i\cdot k_j)e^{G_i-G_j} \cdot scale$）。

**(6) 状态更新**（Step 7 `UpdateAndWriteState`）：

$$S_{out} = e^{G_{L-1}} S_{in} + \sum_{i} e^{G_{L-1} - G_i}\, k_i \otimes v_{new,i}$$

含义：旧状态衰减一个整块（$e^{G_{L-1}}$ = 块内所有 $\gamma$ 的乘积），再把每步的 $v_{new}$（已经扣除了旧状态贡献）按"衰减到块尾"的权重外积累加进去。这就是下一块的 $S_{in}$。

| 数学 | kernel 函数 | 位置 | 产出缓冲 |

| $A$ 直接项 + 递归修正 + 对角线 | `ComputeAttnMatrix` + `ComputeRecursiveAttn` | `chunk_gated_delta_rule.h:576/317` | `chunkScoresFp32` |
