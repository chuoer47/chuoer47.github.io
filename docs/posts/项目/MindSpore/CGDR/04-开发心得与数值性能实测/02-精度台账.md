## 结论先行

1. **正确性状态的整条链是 0 fail → 11 fail → 1 fail → 0 fail**：00e39ab5 全绿（5P/0F/5S）→ d0906c3e 引入 1 个精度 fail（nrmse 0.0269）→ 048d0427 双修复后 **15 passed 0 failed**（`PLAN.md §Step A+B L71`、`L92-93`、`L110`）。
2. **中间 commit 725cf45d 是"输出全零"的坏版本**：11 个 fail 全部由全零导致，构成 = **9 组 tail + beta_zero + recurrent_reference**；`test_shapes_and_dtypes`/`test_optional_g` 因只断言 `torch.isfinite` 而通过（`docs/PR-1135-d0906c3e/10-Commit演进史.md §9.3 L303-310`）。全零的直接证据是探针 absmax：**725cf45d = 0.0/0.0，a9c66ddb/69300ffc/d0906c3e ≈ 0.096/0.023**（`docs/PR-1135-d0906c3e/02-实验复现.md §6.4 L212`）。
3. **同一个精度指标（`test_accuracy_recurrent_reference[fp16]`）在两个版本上的值是连续恶化的**：d0906c3e cos=0.9996 / nrmse=0.0269，69300ffc cos=0.9995 / nrmse=0.0319（阈值 cos≥0.999、nrmse≤0.02）。69300ffc 的 nrmse 比终态**更差 18.6%**（本报告计算），但文档把它记为"与终态完全一致"，两处口径需并列看（§2）。
4. **崩溃（稳定性）与精度（正确性）是两条独立的失效线**：崩溃 kernel 后缀随 tilingKey 数从 `_2` 变 `_3`，但 shape 簇、概率量级（~1/3）、硬件错误机理（`L0C read/write conflict`）在整条分支上完全一致（`docs/PR-1135-d0906c3e/02-实验复现.md §6.5 L217-225`）。
5. RGDR（!1140）的 3 failed 只作为 **prefill/decode 分工的对照**，不参与 CGDR 的精度趋势线（§7）。

**归因链（docs 已验证的三步，逐条可溯源）**：

1. **失败只随 kernel 构建走**：单测隔离实验——`beta_zero` 在 725cf45d 构建上**单独跑也挂**（排除测试间状态污染），同一用例在 a9c66ddb / 69300ffc 构建上单独跑都过（`docs/PR-1135-d0906c3e/10 §9.3 L309-310`）。
2. **代码考古 + 排除**：725cf45d 首次引入的 `LoadPaddedRows` 用 `DataCopyPad` 承担全部 K/Q 装载；a9c66ddb 的装载是标准 strided DataCopy，其 kernel.h 中 `DataCopyPad` 出现次数为 **0**（grep 验证）。310P（dav_m200）的 MTE2 对 `DataCopyPad` 支持不完整 → **静默不写数据**：UB 先被 `Duplicate` 清零、`DataCopyPad` 不落数、后续 Cast 全读 0 → 全链路输出全零（`docs/PR-1135-d0906c3e/10 §9.3 L312-321`）。
3. **修复由下一代 commit 承担**：69300ffc 的 commit 注释明写 "using dav-2002 supported primitives"，把 `LoadPaddedRows` 重写成 `Duplicate` 清零 + 标准 DataCopy 分块 + 标量尾巴三段式（同文 §5.2），终态 `src/d0906c3e/op_kernel/chunk_gated_delta_rule.h:274` 即该版本，其函数头注释本地可读到"dav-2002 supported primitives … fill at most 15 tail elements through Scalar"。

**时间窗**：docs 记为"**71 小时窗口内主干上存在一个全零输出的 kernel**"（`docs/PR-1135-d0906c3e/10 §9.3 L323-327`）。按同文 §0 的 commit 日期（725cf45d 8/17 → 69300ffc 8/17 中午）该窗口在同一天内，而 71 小时是按 8/14→8/17 分支跨度算的——**本报告未重算这个时长，原样引用，标注为 docs 口径**。
