# Stars Saying / 假设星星会说话

[stars-saying](https://github.com/chuoer47/stars-saying) —— 我的儿童天文互动学习 Web App,**2026 年第九届中国天文学会天文创新作品大赛(软件产品赛道)国家三等国C奖**。

移动优先的儿童天文学习 Web App:孩子可以随机抽取宇宙朋友、和拟人化星体聊天、查看知识卡片、进入星空课堂,并生成星空愿望卡。

- 在线演示:https://stars-saying.vercel.app
- GitHub:https://github.com/chuoer47/stars-saying
