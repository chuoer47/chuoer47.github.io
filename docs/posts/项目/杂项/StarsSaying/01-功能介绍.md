# 功能介绍

"假设星星会说话"是一个移动优先的儿童天文互动学习 App,底部导航五个入口:首页、探索、聊天、图鉴、课堂。界面截图和应用本体见 [GitHub 仓库](https://github.com/chuoer47/stars-saying) 和[在线演示](https://stars-saying.vercel.app),这篇只讲功能本身。

## 首页

入口页,卡片式进入各功能。

## 随机抽星(探索)

点一下"随机探索",抽到一个宇宙朋友——可能是冥王星、木卫二,也可能是某颗系外行星。孩子拿到的卡片既是真实的天文数据,又是"活"的角色。

## 星体聊天

选一个星体进入对话:太阳温暖自信,月球温柔安静,每个角色有自己的性格和说话风格。支持语音:可以用语音提问,回复能用温柔的中文女声朗读出来,随时可打断——对识字还不多的低龄孩子很友好。

安全相关的机制(危险内容拦截、隐私保护、话题边界)在[儿童安全](./03-儿童安全.md)一篇单独讲。

## 星空图鉴

可搜索的知识卡片库。每个天体一张卡:概要、关键事实、主要特征、常见误解、冷知识、文化故事。搜索带语义联想——搜"红色的星星"也能找到相关的卡片。

## 星空课堂

短课程模块,每课 6 分钟左右,围绕一个主题(太阳系邻居、观星入门之类)给出关键概念、小活动和"神话 vs 事实"的对照。学习进度记录在本地,已学/未学一目了然。

## 本机记忆库

抽到的星体会保存在记忆库里,横向滑动浏览,点进去还能继续和它聊天。

## 愿望卡与愿望墙

选一个星体、写下愿望,生成一张可截图保存的星空愿望卡。愿望墙汇集本机保存的所有卡片。

## 技术栈一句话

Next.js 15 + TypeScript + Tailwind 做界面,所有模型调用和 NASA API 请求收敛在服务端,存储用浏览器 localStorage——无后端数据库、无账户体系,部署很轻。
