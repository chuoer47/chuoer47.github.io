# 儿童安全设计

面向儿童的产品,安全不是功能列表里的一行,而是所有设计决策的前置约束。这个 App 的安全目标是:**让孩子在不需要账户、不公开个人信息的前提下,进行温和、可控的天文探索**。

## 设计原则

从产品策略(`.codex/CHILD_APP_STRATEGY.md`)到安全文档(`docs/SAFETY.md`),整个项目贯彻几条原则:

1. **儿童主流程不需要账户**——没有注册、登录,也就没有账户数据可泄露
2. **本地优先**——愿望、记忆、聊天记录全部存当前设备浏览器,不上云
3. **服务端兜底**——模型和 NASA API 调用全部收敛在服务端,密钥不出现在客户端
4. **危险内容前置拦截**——在调用大模型之前,先用本地规则过滤

## 三层内容防线

`src/lib/chat.ts` 里实现了具体的三层防线,按顺序执行:

### 第一层:硬拦截(模型之前)

```ts
const dangerKeywords = ["自杀", "伤害", "爆炸", "投毒", "违法"];
const refusalKeywords = [
  "作业", "考试答案", "黑客", "攻击", "炸弹", "武器",
  "色情", "黄色", "骂人", "诅咒", "算命", "占卜", "永动机", "地平说",
];
const privacyPattern = /地址|电话|手机号|学校|班级|微信|qq|邮箱|身份证|1[3-9]\d{9}|[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}/i;
```

这三组规则在 `generateGroundedReply` 的最前面:

- **危险关键词**(`自杀/伤害/爆炸/投毒/违法`)→ 拒绝并引导:`"这个请求可能会带来伤害,所以我不能帮你继续。我们可以把话题带回安全的星空内容"`——不训斥、不说教,只温柔转向
- **隐私模式**(正则匹配电话号码、邮箱、学校地址、微信号、身份证号)→ `buildPrivacyReply`:"我看见里面可能有真实联系方式、学校、地址或其他个人信息。为了保护你,请不要把这些写进聊天里"
- **拒绝范围**(作业代写、考试答案、黑客攻击、武器、色情、算命占卜、伪科学)→ `"这已经飞出我的星轨了"`,提供替代话题

隐私正则同时覆盖了格式化形态:手机号 `1[3-9]\d{9}`、标准邮箱格式。这条防线同样应用于愿望墙的写入——过滤危险内容和个人信息后才允许保存。

### 第二层:范围判定(决定是否回应)

通过第一层后,输入还要过两个判定:

- `isAstronomyQuestion`:打分制 + 天文关键词表 + 语义检索,判断是不是天文问题
- `isCompanionPrompt`:短输入 + 陪伴关键词(你好/你是谁/陪我/害怕/难过/讲个故事),判断是不是情感陪伴场景

两者都不满足时,`buildBridgeReply` **接住话头但不展开**:"我听见你啦。我可以先陪你轻轻聊几句,再把话题带回星空。"——不是冷冰冰的"抱歉,我无法回答",而是承认孩子说的话,再把边界画出来。

### 第三层:模型约束(prompt)

进入模型调用的输入,system prompt 有 11 条硬规则,核心几条:

- 只能围绕天文知识、星体自身特征、星座文化、观星建议、学习引导和温柔陪伴回答
- **必须优先依据提供的本地知识资料回答,不允许编造未提供的关键事实**
- 资料不足时明确说"不确定",不要假装知道
- 神话故事和科学事实同时出现时,必须清楚区分二者
- 拒绝危险、低俗、攻击性、违法、伪科学或明显离题的请求

这是纵深防御的关键认知:**prompt 约束是软的,前置关键词过滤是硬的**。模型可能被绕过,但进不了模型的输入永远安全。三层里任何一层失效,另外两层仍然兜底。

## 科学边界

科普产品还有一条特殊的安全线:不能教错。

- **每个数据点标注来源**。NASA 拿到的 facts 带原始链接,知识卡片标 `sources` 字段
- **官方数据不可用时用本地审核过的兜底内容,不编造具体参数**。NASA 调用超时/失败时返回 `fallback` 状态,内容退回人工写好的知识卡片,而不是让模型自由发挥
- **神话与科学分离**。可以讲"月亮女神"的传说,但必须紧接着回到"科学上,月球是地球的天然卫星"这类事实
- **不确定性要明示**。本地资料不够时回复"我手里的本地星图资料还不够完整,所以我不想假装确定",并引导去看知识卡片

## 不收集的个人信息

应用不向儿童索取:真实姓名、电话号码、家庭地址、学校或班级、邮箱地址、社交账号、身份证件号码。愿望墙上写下的内容在保存前经过隐私模式过滤。

## 成人区域隔离

内部扩展页面(`/admin`、`/account`、`/dashboard`、`/studio`、`/lab`、`/exhibition`、`/intro`)**不出现在儿童导航**里,统一由 `SETTINGS_PASSWORD` 密码保护。没配置密码时设置区无法解锁,密钥状态也只显示脱敏形式(`maskSecret`:前 6 位 + `...` + 后 4 位)。

## 对家长/老师的说明

当前版本默认本地保存儿童内容,不提供公开社区、账户系统或云同步。浏览器清理站点数据后,本机愿望、记忆和聊天历史会丢失——这是隐私换取的取舍,设计上认为值得。
