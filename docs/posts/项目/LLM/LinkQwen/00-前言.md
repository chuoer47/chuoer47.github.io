## Qwen3.5 简介

- [arxiv技术论文](https://arxiv.org/pdf/2604.15804)
- [Huggingface Qwen3.5 0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B)
- [ModelScope Qwen3.5 0.8B](https://www.modelscope.cn/models/Qwen/Qwen3.5-0.8B)

**Qwen3.5** 是通义千问团队开发的大语言模型系列，相比前代的核心架构创新：

| 特性 | 说明 |
|------|------|
| **SwiGLU 激活函数** | 替代传统 ReLU FFN，门控机制提升表达能力 |
| **RMSNorm** | 替代 LayerNorm，去掉均值中心化，计算更高效 |
| **RoPE 旋转位置编码** | 旋转不变性编码相对位置，支持长序列 |
| **Partial RoPE** | 只对 head_dim 的前 25% 做 RoPE，其余直通 |
| **GQA 分组查询注意力** | 8 个 Q head 共享 2 个 KV head，平衡效率和性能 |
| **Sigmoid Gate** | 注意力输出乘以 sigmoid(gate)，替代传统的残差直接相加 |
| **Gated DeltaNet** | O(n) 线性注意力，用递归状态矩阵压缩历史信息 |
| **混合层布局** | 每 4 层中 3 层用线性注意力 + 1 层用全注意力 |

本教程仅考虑其中的 **文本模型**
