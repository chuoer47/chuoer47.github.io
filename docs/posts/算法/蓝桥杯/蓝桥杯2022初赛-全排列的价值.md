# 蓝桥杯 2022 初赛 - 全排列的价值

题目来源：[P2052 - 全排列的价值](http://oj.ecustacm.cn/problem.php?id=2052)



## 分析

这是一个简单的动态规划，把 f(n) 记作第 n 个数的答案（不取模）

那么我们可以把 f(n) 与 f(n-1) 的关系写出来，主要的思想为：把数字 n 插入到 n-1 个数字中，因为 n 大于前面的 n-1 个数字，因此不改变 n-1 的相对大小，同时我们可以知道一共有 n 个空位可以插入。

公式如下：

```
f(n) = f(n-1) * n + (n*n-n) / 2 * (n-1)!
```

代码实现简单，如下：

```python
n = int(input())
res = 0
tem = 1
for i in range(2,n+1):
    res = res*i + int((i*i-i)/2)*tem
    tem *= i
print(int(res%998244353))
```

测试了一下 5000，1 秒内出来了。测试了 10000，也是 1 秒内出来了。不过到 1000000，跑不出来，想想也正常，毕竟 1000000！的量级 python 的 int 都存不下。不过应该可以拿到不少分数。
