## 试题 D: 平均

题目来源：[P2104 - 平均](http://oj.ecustacm.cn/problem.php?id=2104)

是个比较基础的题目了，主要就是排序啦，要是想优化可以利用优先队列取出溢出的前几个最小的。不过比赛的时候懒得尝试，赶时间，直接 sort 了。估计还是水到了一点分数。

```python
n = int(input())
arr = [list(map(int,input().split(" "))) for i in range(n)]
cot = [0 for i in range(10)]
pri = [[] for i in range(10)]
for i in range(n):
    a,b = arr[i][0],arr[i][1]
    cot[a] += 1
    pri[a].append(b)
for i in range(n):
    pri[a].sort()
aver = n//10
res = 0
for i in range(n):
    if cot[i]>aver:
        t = cot[i]-aver
        res += sum(pri[i][0:t:1])
print(res)
```
