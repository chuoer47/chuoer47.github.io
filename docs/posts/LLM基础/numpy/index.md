# NumPy

NumPy（Numerical Python）是 Python 科学计算的基石库，提供了高性能的多维数组对象 `ndarray` 和丰富的数学函数库。它是 Pandas、Scikit-learn、TensorFlow、PyTorch 等众多数据科学与机器学习框架的底层依赖。

::: tip 版本说明
本笔记基于 NumPy 2.x 编写，核心概念同样适用于 NumPy 1.x。
:::
