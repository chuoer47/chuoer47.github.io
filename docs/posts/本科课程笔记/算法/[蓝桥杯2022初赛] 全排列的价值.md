# [蓝桥杯2022初赛] 全排列的价值

题目：

来源：[P2052 - [蓝桥杯2022初赛] 全排列的价值 - New Online Judge (ecustacm.cn)](http://oj.ecustacm.cn/problem.php?id=2052)

![](https://i-blog.csdnimg.cn/blog_migrate/65825e71eca497e99a596b51051a3636.png)

 分析：

这是一个简单的动态规划，把f(n)记作第n个数的答案(不取模)

那么我们可以把f(n)与f(n-1)的关系写出来，主要的思想为：把数字n插入到n-1个数字中，因为n大于前面的n-1个数字，因此不改变n-1的相对大小，同时我们可以知道一共有n个空位可以插入。

公式如下：

 f(n) = f(n-1) * n + (n*n-n) / 2 * (n-1)!

 代码实现简单，如下：

```
n = int(input())
res = 0
tem = 1
for i in range(2,n+1):
    res = res*i + int((i*i-i)/2)*tem
    tem *= i
print(int(res%998244353))

```
