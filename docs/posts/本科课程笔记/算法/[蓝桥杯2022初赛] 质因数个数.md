# [蓝桥杯2022初赛] 质因数个数

题目来源：

[P2055 - [蓝桥杯2022初赛] 质因数个数 - New Online Judge (ecustacm.cn)](http://oj.ecustacm.cn/problem.php?id=2055)

题目：

![](https://i-blog.csdnimg.cn/blog_migrate/d76d2069377edbb931121b0f42b9d3c6.png)

 分析：

由于时间限制，要是从2开始遍历n，找到质数再判断是不是约数，可能导致时间不够。

因此采用了先找约数，再判断是否为质数，是的话加入集合，由于python集合特性，不需要判断重复的，分析比较简单，代码实现如下：

```
import math
import time
def isZ(n):
    if (n<2):
        return False
    for i in range(2,int(math.sqrt(n))+1):
        if n%i==0:
            return False
    return True

n = int(input())
start = time.time()
set = set()
flag = True
while flag:
    flag = False
    for i in range(2,int(math.sqrt(n))+1):
        if n%i==0:
            flag = True
            n = n//i
            if isZ(i):
                set.add(i)
if isZ(n):
    set.add(n)

print(len(set))

end = time.time()
print("耗时：",end-start)

```
后面时间判断可以删去，时间只是为了测试用。

注意一点：

```
n = n//i
```
防止浮点数导致计算失败。
