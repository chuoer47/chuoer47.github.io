# CrewAI 多智能体框架教程

从零开始掌握 CrewAI 多智能体协作框架，涵盖核心概念、Agent 与 Task 设计、工具系统、记忆机制、Flows 工作流编排，以及生产环境最佳实践。

## 教程目录

1. **CrewAI 概述与环境搭建** — 框架定位、架构设计、安装配置、快速上手
2. **Agent 详解** — 角色定义、目标设定、背景故事、LLM 配置、委托机制
3. **Task 与 Crew 详解** — 任务定义、上下文传递、顺序/层级执行、结构化输出
4. **工具系统** — 内置工具、`@tool` 装饰器、`BaseTool` 自定义工具、工具集成
5. **记忆系统** — 短期记忆、长期记忆、实体记忆、自定义嵌入器
6. **Flows 工作流编排** — 事件驱动、状态管理、条件路由、多 Crew 编排
7. **实战案例与最佳实践** — 完整项目、常见模式、生产部署、框架对比

## 适用人群

- 有 Python 基础的开发者
- 想要构建多 Agent 协作系统的工程师
- 对 AI Agent、自动化工作流感兴趣的同学

## 技术栈

| 组件 | 版本 |
|------|------|
| Python | 3.10 ~ 3.12 |
| CrewAI | 最新版 |
| LiteLLM | 内置（支持 100+ LLM 提供商） |
| ChromaDB | 内置（短期/实体记忆） |
| SQLite | 内置（长期记忆） |
